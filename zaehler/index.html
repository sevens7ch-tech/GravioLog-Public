So lesen Sie die Zahlen

Webseite: jeder Klick auf „APK herunterladen“, der die Datei wirklich lädt – auch eigene Tests. Der Wert wird mit jeder neuen Version weitergezählt.

Updates: GitHub zählt jeden Download einer Version. Installierte Handys holen sich jede neue Version selbst, deshalb steigt diese Zahl mit jeder Version um etwa die Zahl der aktiven Handys. Wie viele verschiedene Personen das sind, zeigt GitHub nicht.

Grün „+ …“ zeigt, was seit Ihrem letzten Besuch dieser Seite in diesem Browser dazugekommen ist.

Quelle: öffentliche Zahlen von GitHub (Gravio-Updates). Sie können ein paar Minuten verzögert sein. Diese Seite ist nicht verlinkt und für Suchmaschinen gesperrt.
